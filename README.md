## About the Project

This portfolio was developed as a React.js learning project and as a personal professional website.

The main objective is to practice modern React development while building a professional interface that presents my technical profile, projects, experience, and contact information.

The project focuses on:

- Component-based development
- React JSX
- React state management
- Props
- Array rendering with `map()`
- Controlled forms
- Responsive CSS
- Semantic HTML
- Git and GitHub workflow
- Clean project organization
